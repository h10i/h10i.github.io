Ubuntu 24.04 LTS を 26.04 LTS にアップグレードする

Published: 2026-06-06
  • #Ubuntu

概要

  • Ubuntu 24.04 LTS を 26.04 LTS にアップグレードする
  • 26.04.01 LTS リリース前のため、安定版を求める場合は 26.04.01 LTS のリリース後のアップグレードを推奨する。

環境

lsb_release -a
No LSB modules are available.
Distributor ID: Ubuntu
Description:    Ubuntu 24.04.4 LTS
Release:        24.04
Codename:       noble

手順

アップグレードの準備

既存のパッケージを最新化する。

sudo apt update && sudo apt upgrade -y

必要に応じて再起動する。

systemctl reboot

アップグレードするバージョンの確認

アップグレード対象をチェックする。

do-release-upgrade -c

26.04.1 LTS はまだリリースされていないため、表示されない。

Checking for a new Ubuntu release
There is no development version of an LTS available.
To upgrade to the latest non-LTS development release
set Prompt=normal in /etc/update-manager/release-upgrades.

-d (--devel-release) オプションをつけて再度確認する。

do-release-upgrade -c -d

26.04 LTS が表示される。

Checking for a new Ubuntu release
New release '26.04 LTS' available.
Run 'do-release-upgrade' to upgrade to it.

アップグレード

-d オプションを付与し、アップグレードコマンドを実行する。

sudo do-release-upgrade -d

リリース情報が表示されるため、y を入力する。

Continue [yN]

公式リポジトリ以外からインストールした外部パッケージがあるが、アップグレードを進めて良いか聞かれるため、y を入力する。

...

The following unofficial packages are currently installed:

...

It is recommended to install supported versions from the Ubuntu
archive, and try the upgrade again.

Do you want to continue the upgrade anyways?

Continue [yN]

アップグレードを開始して良いか最終確認が表示されるため、y を入力する。

...

Do you want to start the upgrade?


22 packages are going to be removed. 324 new packages are going to be
installed. 1653 packages are going to be upgraded.

You have to download a total of 2,573 M. This download will take
about 11 minutes with your connection.

Installing the upgrade can take several hours. Once the download has
finished, the process cannot be canceled.

 Continue [yN]  Details [d]

一時的にロックスクリーンを無効化したとの情報が表示されるため、Enter を入力する。

Lock screen disabled

Your lock screen has been disabled and will remain disabled during
the upgrade.

To continue please press [ENTER]

アップグレードが始まるため、完了までしばらく放置する。

都度確認が表示されるため、内容に応じて選択する。

アップグレードが完了すると再起動を求められるため、y を入力する。

...

System upgrade is complete.

Restart required

To finish the upgrade, a restart is required.
If you select 'y' the system will be restarted.

Continue [yN]

再起動が完了するまでしばらく放置する。

バージョンを確認する。

lsb_release -a

26.04 LTS になっていることを確認する。

No LSB modules are available.
Distributor ID: Ubuntu
Description: Ubuntu 26.04 LTS
Release: 26.04
Codename: resolute
